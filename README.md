# Paint & Glow Kids Shop

A clean, responsive e-commerce prototype for pre-cast painting kits and drawing books for children under five.

## Included
- Responsive desktop, tablet and mobile layout
- Product categories, search and sorting
- Product quick-view modal
- Shopping cart with quantity controls
- LocalStorage cart persistence
- Delivery calculation
- Three-step checkout flow
- Mobile navigation
- Accessible labels and reduced-motion support

## Run
Open `index.html` directly in a browser, or run a small local server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Notes
- Checkout and payment are front-end demos only.
- Replace demo product data in `script.js` with API data when connecting a real backend.
- Replace emoji-based illustrations with final product photography before production launch.
